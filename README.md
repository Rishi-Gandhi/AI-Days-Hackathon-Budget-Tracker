# 💰 AI-Powered Expense Tracker

A simple, command-line budget tracker that records your expenses, tracks your remaining budget, and uses OpenAI to give smart spending feedback.  
You can also view a pie chart of your spending by category.

---

## 🚀 Features
- Add expenses in 5 fixed categories: Food, Entertainment, Shopping, Transportation, Random
- Set a total budget and see your remaining balance after each expense
- Get AI feedback after every expense (via OpenAI API)
- Receive alerts when you hit 80 % or exceed your budget
- Optional spending pie chart
- Data saved automatically in a CSV file
